**How to set up the project**
Create .env file - cp .env.example .env
Execute in terminal the `composer install`
Execute in the terminal the `npm install`
Set application key to generate a new application key and store it in the .env file under the APP_KEY variable `php artisan key:generate --ansi`
Allows access to uploaded files stored in storage/app/public from the public/storage folder. `php artisan storage:link`

**Database Migration**
Execute migrations and seed data - `php artisan migrate --seed`

**Run the project**
Start vite server - `npm run dev`
Start Artisan server - `php artisan serve`
